# Project collaboration preferences

For every handoff, save a dated Markdown file in reports/ using the local date in
America/Los_Angeles, for example CONTINUE_TOMORROW_YYYY-MM-DD.md. If a handoff for
that date already exists, add the local HHMMSS timestamp to the new filename;
never overwrite the earlier dated handoff. An undated convenience copy may also
be kept. Include a link to the dated handoff in the response.
