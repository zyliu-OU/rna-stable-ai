# Retained data attribution

OpenVaccine: author-provided processed `Kaggle_RYOS_trainset.json` from
https://github.com/eternagame/KaggleOpenVaccine at commit
`b95af835cc38bd7dc55ed6e7397d124787f86996`. The upstream MIT license is retained
in `third_party/KaggleOpenVaccine_LICENSE.txt`. The10,260,945-byte source SHA-256 is
`bd1e611d7c9b626c5266eadda33cc3b50c28db146d1bbccdf15e8f33485ce3e5`.
This author file contains1589 processed records; the64-row pilot is not the full
original Kaggle competition dataset. Source provenance and measured coordinates
are retained in the acquisition/binding manifests.

Prospective structure evidence: Rfam alignments and referenced PDB/RNAcentral
records are retained with source URLs and hashes in each acquisition/evidence
manifest. Unsupported annotations remain explicit; these are not invented
reference structures. Earlier comparative data keep their source manifests.
Consult those manifests and upstream attribution when reusing data.

Per-sequence PDB-derived annotations: official
`Rfam/rfam-3d-seed-alignments`, commit
`a22cc827b5b99a3e97935384cc0812b73bc49668`. The Apache-2.0 license and source
pipeline are retained in
`results/structure_derived_source_runs/20261015T021501.529110Z/source/`.
Git blob identities, source file sizes, and SHA-256 values are frozen before
acquisition. These are supplied FR3D/PDB-derived cWW strings, not direct probing
measurements or verified complete raw interaction graphs. See
[reference engineering](STRUCTURE_DERIVED_REFERENCES.md).

Raw FR3D contact-provenance audit: six PDB-chain responses from
`https://rna.bgsu.edu/rna3dhub/rest/getSequenceBasePairs` with `only_nested=False`.
Exact URLs, sequence hashes, original contact sets, and retrieved response bytes
are retained under `results/structure_contact_provenance_runs/20261015T022710.758207Z/`.
The source is the BGSU RNA Structural Bioinformatics group's RNA 3D Hub. These
current annotations are versioned locally by acquisition time and byte hash;
they are not asserted to be the annotation version used by the historical source.

Synthetic controls were generated by this project's scripts with declared seeds.
Experimental checkpoints and generated predictions are research outputs; they
are not validated RNA stability or function models. Dependencies and installed
third-party executable trees are not vendored.
